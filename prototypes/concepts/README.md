# Four lighter concepts (prototype)

Plain JS + CSS (no WebGL): cinematic film, infinite canvas, 3D carousel,
editorial story. `data.js` (not committed) is generated from
`src/content/galleries/*.json`: `window.LOSPIKIR = [{ slug, title, kind, city,
year, photos: [{ src, thumb, r }] }]`. Once a concept is chosen it gets
rebuilt as part of the site.
