Photographs go here.

Easiest: upload them in the CMS (/admin → Packages or Gallery → Photo), which
drops them in this folder and wires the path for you.

By hand: reference them from src/data/packages.json and src/data/galleries.json
as '/photos/your-file.jpg'. Until then, a tinted gradient stands in.

Export around 2000px on the long edge and compress — these run full-bleed.
